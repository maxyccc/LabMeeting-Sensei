# LabMeeting-Sensei

| Caveat: This readme file is generated by LLM. 🤖🤖🤖

Small Python utility for building figure layouts and exporting them to PowerPoint.

## Install

```bash
pip install pillow python-pptx
```

## Run the example

```bash
python example_create_slides.py
```

This creates:

- `example_result.png`
- `example_result.pptx`

## Project structure

```text
.
|- example_create_slides.py   # demo script
|- example_figs/              # sample images
`- src/
   |- basic_layouts.py        # layout classes (image/text, horizontal/vertical/grid)
   |- images.py               # image sizing/padding/fit helpers
   |- slide_assembly.py       # create/save pptx, add image slide
   |- io.py                   # simple recursive file search
   `- settings.py             # slide size and rendering defaults
```

## Main pieces

- `SingleImageLayout`, `SingleTextLayout`
- `HorizontalLayout`, `VerticalLayout`, `AdaptiveGridLayout`
- `create_presentation()`, `insert_slide()`, `save_presentation()`

## Practical use

`example_create_slides.py` is the template.

For example, the script:

1. Loads `example_figs/1.jpg` to `example_figs/14.jpg`.
2. Wraps each with `SingleImageLayout(...)`.
3. Builds a nested layout with `HorizontalLayout(...)` and `VerticalLayout(...)`.
4. Renders `example_result.png`.
5. Inserts that image into `example_result.pptx`.
